Patch Plan help

A patch plan is a drawing of every device and every cable of a show. Build it here, keep the cable list and quantities in sync, and share it as a file, a print / PDF or a link.

1 · Start

  • File › New project, give it a name (top left).
  • Drag a device from the library (left) onto the canvas, or click it.
  • + New custom device for anything not in the library; Save as library preset to reuse it.
  • Wheel = zoom, Space+drag or right-drag = pan, F = fit everything.

2 · Devices & ports

  • Click a device to edit it in the right panel: name, colour, type, power, icon, shape, ports.
  • Add many numbered ports at once (e.g. 8 × “Out”).
  • Double-click a port to rename it; drag a port onto its own device to move it to another edge.
  • Box-select with a drag on empty canvas; drag any selected device to move them all.

3 · Cables

  • Drag from a port to another port. The cable gets an ID (PWR-001, NET-002 …) by signal type.
  • Drop on a device body or empty space to create the missing port / device.
  • Click a cable or port to highlight the whole signal chain; drag a cable to bend it.
  • K tidies cables, O arranges devices by signal flow, A shows the flow direction.
  • Multicore: select cables, right-click › Bundle into a multicore.

4 · Organise

  • Frames (R) group an area, text (T) adds labels; Ctrl+G frames the selection.
  • Layers (left): show / hide / lock groups of items.
  • Background: load a venue drawing (SVG, PNG, JPG, PDF) and patch on top of it.

5 · Colours & look

  • Signal legend (project panel, click empty canvas): colour, width and line style per signal type; add your own types.
  • Palette swatches colour many selected items at once.
  • 🎨 Style menu, ◐ dark / light, Display section for spacing, text size and font.

6 · Lists & quantities

  • ☰ Lists (C): cables, port usage, devices, quantities.
  • Tick rows (or the header box for all shown) and change them all in the right panel.
  • Quantities: how many of each device, total power and amps, cable metres per type / connector / length.
  • CSV exports what you see.

7 · Save & share

  • The project autosaves in this browser. Ctrl+S saves a .json file — that file is the project.
  • Colleagues open the .json with this same editor (file or web link).
  • Save view-only copy opens locked; 👁 View only locks your own screen.
  • Export PNG / SVG, or Print / PDF (drawing, legend, equipment list, cable totals, cable list).
  • Online: File › Put this project online, choose a password, send the link and (separately) the password. Everyone with both works on the same plan; changes save by themselves (☁ at the top).

8 · Which version am I on?

  • The build number is at the bottom-left of the canvas and saved in every file.
  • What’s new (tab above) lists every build and what it added.
  • Opening a file from a newer build shows a warning.
